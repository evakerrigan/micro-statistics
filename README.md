# microstock-statistics

Расширение для Chrome: собирает продажи из личных кабинетов авторов
микростоков и показывает сводную и раздельную статистику по файлам (фото,
иллюстрации, видео), съёмкам, месяцам и типам лицензий. Сделано на React по
архитектуре [bulletproof-react](https://github.com/alan2207/bulletproof-react).

## Страницы

Вверху под общим заголовком **«Статистика по микростокам»** расположены 4 страницы:

- **Adobe Stock** — активна: сбор портфолио (фото, векторы, иллюстрации и видео), всех продаж и бонусов Firefly из `contributor.stock.adobe.com`.
- **Shutterstock** — активна: сбор портфолио (фото и видео) и всей истории продаж из `submit.shutterstock.com`.
- **iStock** — в планах.
- **Все** — общая статистика по всем подключённым микростокам: карточки по каждому стоку, общий доход, помесячные графики с разбивкой по стокам, объединение по файлам и годам загрузки.

## Установка

```bash
npm install
npm run build
```

1. Откройте `chrome://extensions` и включите **Режим разработчика**.
2. Нажмите **Загрузить распакованное расширение** и выберите папку `dist`.
3. После каждой новой сборки нажмите на карточке расширения кнопку ↻.

## Разработка

| Команда                | Описание                                       |
| ---------------------- | ---------------------------------------------- |
| `npm run dev`          | Dev-сервер Vite (без API Chrome — только UI)   |
| `npm run build`        | Проверка типов (`tsc -b`) и сборка в `dist`    |
| `npm run package`      | Сборка и zip для Chrome Web Store в `release/` |
| `npm run lint`         | Запустить ESLint                               |
| `npm run lint:fix`     | ESLint с автоисправлением                      |
| `npm run format`       | Отформатировать код через Prettier             |
| `npm run format:check` | Проверить форматирование без изменений         |
