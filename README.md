# shutterstock-statistics

Расширение для Chrome: собирает продажи из личного кабинета автора
[Shutterstock](https://submit.shutterstock.com) и показывает, сколько принесли
каждый файл (фото, иллюстрация и видео), съёмка, месяц и тип лицензии. Сделано
на React по архитектуре
[bulletproof-react](https://github.com/alan2207/bulletproof-react).

## Установка

```bash
npm install
npm run build
```

1. Откройте `chrome://extensions` и включите **Режим разработчика**.
2. Нажмите **Загрузить распакованное расширение** и выберите папку `dist`.
3. После каждой новой сборки нажмите на карточке расширения кнопку ↻.

## Как пользоваться

1. Войдите в аккаунт автора на `submit.shutterstock.com` в этом же Chrome.
2. Нажмите на значок расширения — откроется вкладка со статистикой.
3. Нажмите **Загрузить данные**. Запросы идут через вашу текущую сессию. При
   первом запуске загружаются портфолио (фото и видео) и история продаж по дням;
   при последующих обновлениях дозагружаются только новые и изменившиеся дни,
   поэтому обновление занимает несколько секунд.

Интерфейс на английском, кнопка **RU / EN** переключает язык; рядом — переключатель
светлой и тёмной темы. Внизу страницы кнопка **Удалить все данные** стирает из
браузера всё, что сохранило расширение.

Данные хранятся только в браузере (`chrome.storage.local`) и никуда не отправляются.

## Как это работает

Расширение обращается к внутренним JSON-эндпоинтам кабинета автора из открытой
вкладки `submit.shutterstock.com` (`chrome.scripting`, `world: "MAIN"`), поэтому
запросы используют вашу уже открытую сессию.

| Запрос                                  | Данные                                                 |
| --------------------------------------- | ------------------------------------------------------ |
| `/api/next/users/current`               | ID аккаунта, дата регистрации                          |
| `/api/next/v2/earnings/summary`         | общий доход и число лицензированных загрузок           |
| `/api/next/summary/media`               | число опубликованных фото и видео в портфеле           |
| `/api/next/media/search`                | весь каталог фото и видео: ID, описание, превью, дата  |
| `/api/next/v2/earnings/graph`           | активные месяцы с продажами за всё время               |
| `/api/next/v2/earnings/aggregate`       | дневная сводка по категориям лицензий и начислениям    |
| `/api/next/v2/earnings/media_stats/day` | продажи конкретных фото и видео за день и тип лицензии |

Сумма собранных продаж сверяется с общим доходом на дашборде
(`/api/next/v2/earnings/summary`); при расхождении на странице появится
предупреждение. Начисления, не привязанные к отдельному файлу (например,
«Средства автора» / Contributor Fund и рекомендации / Referrals), учитываются в
общем доходе, помесячных графиках и в разбивке по типам лицензий.

Автоматические съёмки формируются по дате загрузки (`uploadedDate`) — объединяя
фото и видео, загруженные в один день. Любую съёмку по дате можно переименовать,
объединить с другой датой (если съёмка загружалась в несколько этапов), либо
отметить нужные файлы и выделить их в свою съёмку. Свои съёмки, переименования
и объединения хранятся отдельно, поэтому повторное обновление их не сбрасывает.

## Публикация в Chrome Web Store

`npm run package` собирает расширение и кладёт архив для магазина в `release/`.
Тексты для страницы магазина и политика конфиденциальности — в папке `store/`
(инструкция: `store/listing.md`).

## Разработка

| Команда                | Описание                                       |
| ---------------------- | ---------------------------------------------- |
| `npm run dev`          | Dev-сервер Vite (без API Chrome — только UI)   |
| `npm run build`        | Проверка типов (`tsc -b`) и сборка в `dist`    |
| `npm run package`      | Сборка и zip для Chrome Web Store в `release/` |
| `npm run lint`         | Запустить ESLint                               |
| `npm run lint:fix`     | ESLint с автоисправлением                      |
| `npm run format`       | Отформатировать код через Prettier             |
| `npm run format:check` | Проверить форматирование без изменений         |

## Структура проекта

Проект следует структуре папок bulletproof-react:

```
src/
├── app/              # слой приложения — связывает всё воедино
├── components/       # общие переиспользуемые компоненты
├── features/         # модули-фичи (самодостаточные)
├── hooks/            # общие хуки
├── lib/              # преднастроенные библиотеки (API-клиент, хранилище, i18n)
├── styles/           # глобальные стили и Sass-переменные
├── types/            # общие типы TypeScript
└── utils/            # общие утилиты
```
